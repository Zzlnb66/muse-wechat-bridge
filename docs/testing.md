## 已通过：本地模拟（不是微信实测）

- 密钥错误 → 失败记录 + 下载字节文件，均为 0600，记录里无密钥值。
- 密钥字段无效 → `KEY_FORMAT_ERROR`；无密钥字段 → 明文路径。
- 失败图片事件 + 追问：处理“这张图写了什么”时得到 `image_reference unavailable`，不描述汤圆图；重启后事件仍为失败。
- 下载长度模拟：声明 79616、实际 73184 → `DOWNLOAD_LENGTH_MISMATCH`，不送解密。
- 重试模拟：第一次短、第二次完整 → 重试成功、只入队一次、两次证据分开；两次都短 → 失败、证据分开。
- 安全密文诊断：完整密文首块能解出 PNG 魔数；密文头本身为 UNKNOWN。
- 无 Range 自动拼接：代码里没有自动拼接逻辑（静态检查）。
